# memamun.github.io

> Personal website hosted on GitHub Pages

## Project Status: **Complete** ✅

A personal website/blog built with Jekyll and hosted on GitHub Pages.

## Tech Stack

- **Framework:** Jekyll (Static Site Generator)
- **Hosting:** GitHub Pages
- **Theme:** Minimal (likely)

## Features

- Static website
- Blog posts (_posts)
- Custom styling
- Fast loading

## Getting Started

1. Install Jekyll:
   ```bash
   gem install jekyll
   ```

2. Run locally:
   ```bash
   jekyll serve
   ```

3. Open http://localhost:4000

## Project Structure

```

├── _site/               # Generated site
├── _config.yml          # Jekyll config
```
